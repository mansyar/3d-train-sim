## Summary

The repository has no README and no contributor-facing entry point — the
only docs are conductor-internal (`conductor/workflow.md`,
`tech-stack.md`, `product.md`) and `e2e/README.md`. This chore track
adds a top-level `README.md` (what Tiny Tracks is, for parents and
developers), a `CONTRIBUTING.md` onboarding guide (setup, gates, the
conductor track workflow, commit conventions, Blender asset recipes),
and light cross-links — with the deep material staying where it lives
in `conductor/` as the source of truth.
