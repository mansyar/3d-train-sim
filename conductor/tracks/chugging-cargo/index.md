# Track: Chugging Cargo

**ID:** `chugging-cargo` · **Type:** Feature · **Status:** new

- [Specification](spec.md) — two trailing cargo wagons on every locomotive
- [Implementation Plan](plan.md) — phased task list (TDD catalog, ride
  following, lifecycle, e2e)
- [Metadata](metadata.json) — registry record

Give every locomotive a proper little train: two bundled Kenney cargo wagons
that trail the selected engine along the solved path — riding, pausing at
stations, reversing at dead ends, and easing to a stop together. No kid UI,
no persistence changes; the joy is purely visual.
