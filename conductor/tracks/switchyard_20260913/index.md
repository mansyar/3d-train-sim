# Track — Switchyard: Three-Way Junction & Motorized Levers (`switchyard_20260913`)

- Type: Feature
- Status: new
- Branch: `track/switchyard_20260913`

A three-way junction piece (one stem, three roads — straight, right, left — cycling
fairly) plus motorized point levers on every switch piece: a chunky lever's arm
swings to the road the points are set for as the train takes it. No new controls,
no reading, no fail states.
